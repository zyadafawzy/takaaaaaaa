# UI/UX Refinement Plan

Improve the overall look and feel of the application with a focus on premium Egyptian mobile shopping experience.

## 1. Visual Polish & Branding
- **Typography**: Refine Cairo/IBM Plex Sans hierarchy.
- **Colors**: Deepen the dark mode surface levels for better depth.
- **Components**: Add subtle micro-interactions and smooth transitions.

## 2. Storefront UX Enhancements
- **Home Page**: Modernize the search bar and hero section.
- **Product Cards**: Improve layout for price visibility and "Add to Cart" feedback.
- **Product Detail**: Clean up spacing and improve image gallery interactions.
- **Cart & Checkout**: Streamline the summary view for mobile clarity.

## 3. Navigation & Feedback
- **Bottom Nav**: Improve icon clarity and active states.
- **Toast Notifications**: Style specifically for the Egyptian context.

## Technical Details
- **CSS**: Use Tailwind v4 native variables.
- **Performance**: Ensure images remain optimized (WebP).
- **RTL**: Maintain strict RTL consistency.
